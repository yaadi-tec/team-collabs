1. Read `AGENTS.md` before starting.

2. We're adding the design system and UI primitive components.

3. Install and configure `shadcn/ui`.

4. Add these shadcn components:
   - Button
   - Card
   - Dialog
   - Input
   - Tabs
   - Textarea
   - ScrollArea

5. Do not modify the generated `components/ui/*` files after installation.

6. Also install `lucide-react`.

7. Create `lib/utils.ts` with a reusable `cn()` helper for merging Tailwind classes.

8. Ensure all components match the existing dark theme in `globals.css`.

---

### Check when done

- All components import without errors
- `cn()` works properly
- No default light styling appears
